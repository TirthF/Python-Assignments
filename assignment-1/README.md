# Python Assignment 1

This repository contains my solutions for Python Assignment 1. The assignment consists of 10 practical programming problems covering a variety of topics including data structures, file I/O, OOP, threading, and GUI development.

## Project Structure

- `Q_1.py`: Campus Merit Analyzer Implementation
- `Q_2.py`: Password Strength Checker
- `Q_3.py`: Expression Evaluator
- `Q_4.py`: CSV Processor
- `Q_5.py`: Banking System
- `Q_6.py`: Module Dependency Resolver
- `Q_7.py`: Interactive Calculator
- `Q_8.py`: Log Indexer
- `Q_9.py`: Multi-Threaded Job Scheduler
- `Q_10.py`: GUI Tracker (Tkinter)

## How to Run

Each question is implemented as a standalone Python script. You can run any of the scripts individually using Python 3. For example:

```bash
python Q_1.py
```

Test cases for the problems are provided in `test_cases.txt`.

## Requirements
- Python 3.x
- Standard built-in libraries (no external dependencies required)
