# Python Assignments & Coursework

A collection of Python assignments and a mini-project completed for my college Python programming course.

## What's Inside

- **[assignment-1/](assignment-1/)** — 10 foundational problems covering OOP, file I/O, regex, data structures, multithreading, and Tkinter basics.
- **[assignment-2/](assignment-2/)** — 10 advanced problems covering MySQL analytics, dynamic programming, log anomaly detection, GUI contact management, and Matplotlib data visualization. Includes a batch test script (`test_all.py`).
- **[MiniProject/](MiniProject/)** — A Tkinter GUI desktop app for enrollment number and institutional email validation, including the project report and presentation slides.

## Getting Started

Most programs use Python's built-in standard library with zero extra dependencies.

To run scripts that use external libraries (Assignment 2):
```bash
pip install mysql-connector-python matplotlib
```

### Running the Code

Run any script directly with Python 3:

```bash
# Run a specific script
python assignment-1/Q_1.py

# Run Assignment 2 tests
cd assignment-2
python test_all.py

# Run the Mini Project
cd MiniProject
python "Username and Email validation system.py"
```
